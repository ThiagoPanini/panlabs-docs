# panlabs.esteira

**Module** · `panlabs.esteira`

Describe the pipeline in Python and emit the GitHub Actions YAML from it. The module exposes two types and three functions, and nothing beyond that is contract: any name with a leading underscore moves between minor versions without notice.

The order of use is the order of the export list: build the pipeline, add the jobs, generate. The snippet beside this page is that whole sequence.

## Exports

| Name | Kind | What it is |
| --- | --- | --- |
| [`Esteira`](./esteira.mdx) | Type | The whole pipeline as an object, with the workflow name, the events that trigger it, and the token permissions. |
| [`Passo`](./passo.mdx) | Type | One step of a job, either a command it runs, or a third-party action pinned to a sha. |
| [`Esteira.trabalho`](./esteira-trabalho.mdx) | Function | Adds a job to the pipeline, with its steps and the dependencies it waits on. |
| [`Esteira.gerar`](./esteira-gerar.mdx) | Function | Validates the whole pipeline and writes the YAML, or returns the refusals and writes nothing. |
| [`padrao.python`](./padrao-python.mdx) | Function | The steps the house uses on a Python repository, with test, types, format and scan, in that order. |
