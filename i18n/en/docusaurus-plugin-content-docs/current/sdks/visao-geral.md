# Overview

Three official SDKs: [**Node**](node), [**Python**](python) and [**Go**](go). All
three are generated from the same OpenAPI contract the API reference publishes,
so none of them knows a field the reference does not document.

## What the SDK does for you

| | Without an SDK | With an SDK |
| --- | --- | --- |
| Authentication | header by hand | constructor |
| Idempotency | key by hand | generated by default, and overridable |
| Retries | yours | exponential backoff on `429` and `5xx` |
| Pagination | cursor by hand | iterator |
| Webhook signatures | HMAC by hand | one verification call |

The last two rows are the real reason SDKs exist. A cursor implemented wrong
returns repeated pages; HMAC verification implemented wrong accepts forged
requests.

:::note[The SDK-generated key protects its retries, not yours]

With no key declared, the SDK generates one and reuses it across its **own**
attempts — that is what makes its exponential backoff safe. It does not survive
the call: a second `criar` generates another key and creates another charge. To
tie idempotency to **your** order, declare the key, as every recipe does.

:::

## Where the three diverge

| | Node | Python | Go |
| --- | --- | --- | --- |
| Minimum version | 20 | 3.10 | 1.23 |
| Async form | the only one | second constructor | `context.Context` |
| Types | bundled | bundled | native |
| **Snippet in the API reference** | yes | yes | **no** |

The last row is a declared loss, not an omission: per-endpoint examples ship in
cURL, Node and Python, and the Go recipe needs named per-endpoint types the
OpenAPI contract does not carry. The [Go](go) page is its canonical surface.

## What stays HTTP

A new resource shows up in the API before it shows up in the SDK. All three
expose an escape hatch for raw requests against the same base URL and the same
key — and reaching for it is not a sign that something is wrong.

## Versioning

The SDK versions itself, in SemVer. The **API** versions by header,
`Trilho-Version: 2026-01-15`. Bumping the SDK does not change the API version you
speak; they are two clocks, and the header is what decides the response format.
