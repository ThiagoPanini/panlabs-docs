# Create a customer

<VerbBadge verb="POST" /> `/clientes`

Creates a customer. Storing the `id` is what lets you save a card and a subscription without repeating data on every charge.

## Parameters

<ParamField name="Idempotency-Key" type="string" required>
A key you choose, up to 255 characters. Repeating the call with the same key and the same body, within 24 hours, returns the original response instead of creating again.
</ParamField>

## Body

<ParamField name="nome" type="string" required>
The full name.
</ParamField>

<ParamField name="email" type="string" required>
Used for receipts and notifications.
</ParamField>

<ParamField name="documento" type="string" required>
CPF or CNPJ, digits only.
</ParamField>

<ParamField name="telefone" type="string">
In E.164.
</ParamField>
