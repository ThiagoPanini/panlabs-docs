# List refunds

<VerbBadge verb="GET" /> `/reembolsos`

The account’s refunds, most recent first, cursor-paginated.

## Parameters

<ParamField name="limite" type="integer" default="20">
How many items per page. Maximum 100.
</ParamField>

<ParamField name="a_partir_de" type="string">
The cursor of the last page read. Omit to get the first page.
</ParamField>

<ParamField name="cobranca_id" type="string">
Filters to the refunds of a single charge.
</ParamField>

## Response

<ResponseField name="dados" type="array of object">
The refunds on this page.

<Expandable title="each item of dados" defaultOpen>

<ResponseField name="id" type="string">
The refund identifier, prefixed `reemb_`.
</ResponseField>

<ResponseField name="cobranca_id" type="string">
The refunded charge.
</ResponseField>

<ResponseField name="valor" type="integer">
In cents. Partial is allowed — the sum of refunds never exceeds the original amount.
</ResponseField>

<ResponseField name="motivo" type="string">
Free-form, yours. Shows on the payer statement when the method supports it.
</ResponseField>

<ResponseField name="status" type="string">
Pix and boleto complete in minutes; card can take days, depending on the issuer.

Possible values: `pendente`, `concluido`, `falhou`.
</ResponseField>

<ResponseField name="criado_em" type="string">
When the refund was requested.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_pagina" type="string">
The cursor for the next call. Null on the last page.
</ResponseField>
