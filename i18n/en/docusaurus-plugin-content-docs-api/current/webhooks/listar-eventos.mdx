# List events

<VerbBadge verb="GET" /> `/eventos`

The account’s event history, most recent first — useful to reconcile against what webhooks already delivered.

## Parameters

<ParamField name="limite" type="integer" default="20">
How many items per page. Maximum 100.
</ParamField>

<ParamField name="a_partir_de" type="string">
The cursor of the last page read. Omit to get the first page.
</ParamField>

<ParamField name="tipo" type="string">
Filters by a single type, like `cobranca.paga`.
</ParamField>

## Response

<ResponseField name="dados" type="array of object">
The events on this page.

<Expandable title="each item of dados" defaultOpen>

<ResponseField name="id" type="string">
The event identifier, prefixed `evt_`. It is the deduplication key.
</ResponseField>

<ResponseField name="tipo" type="string">
The event name, like `cobranca.paga`.
</ResponseField>

<ResponseField name="ocorrido_em" type="string">
When the event occurred — not when it reached your server.
</ResponseField>

<ResponseField name="versao_api" type="string">
The API version under which the event was emitted.
</ResponseField>

<ResponseField name="dados" type="object">
The payload, which varies by `tipo`.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_pagina" type="string">
The cursor for the next call. Null on the last page.
</ResponseField>

## Errors

| Status | When |

| `401` | The key is missing, invalid, or from another environment. |
| `429` | Rate limit exceeded. The header says how many calls remain. |
