# The Evento object

An event — what a webhook delivers. `dados` varies by `tipo`; the full catalog is in Webhooks › Event catalog.

The complete shape of `Evento`, as any endpoint in this section returns it.

<ResponseField name="id" type="string">
The event identifier, prefixed `evt_`. It is the deduplication key.
</ResponseField>

<ResponseField name="tipo" type="string">
The event name, like `cobranca.paga`.
</ResponseField>

<ResponseField name="ocorrido_em" type="string">
When the event occurred — not when it reached your server.
</ResponseField>

<ResponseField name="versao_api" type="string">
The API version under which the event was emitted.
</ResponseField>

<ResponseField name="dados" type="object">
The payload, which varies by `tipo`.
</ResponseField>
