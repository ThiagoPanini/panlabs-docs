# Capture a charge

<VerbBadge verb="POST" /> `/cobrancas/{id}/capturar`

Captures a card charge authorized with `capturar: false`. Capturing less than authorized releases the difference; capturing more is not allowed.

## Parameters

<ParamField name="id" type="string" required>
The charge `id`.
</ParamField>

## Body

<ParamField name="valor" type="integer">
In cents, up to the authorized amount.
</ParamField>

## Response

<ResponseField name="id" type="string">
The charge identifier, prefixed `cob_`.
</ResponseField>

<ResponseField name="status" type="string">
The current state. `recusada` is a successful `201` — the request was correct and the financial system said no.

Possible values: `pendente`, `paga`, `recusada`, `expirada`, `cancelada`, `estornada`.
</ResponseField>

<ResponseField name="valor" type="integer">
In cents. Always an integer.
</ResponseField>

<ResponseField name="moeda" type="string" default="BRL">
Only `BRL` today. The field exists for the day it is not.
</ResponseField>

<ResponseField name="meio" type="string">
The chosen payment method.

Possible values: `pix`, `boleto`, `cartao`.
</ResponseField>

<ResponseField name="capturar" type="boolean" default="true">
Card only. `false` authorizes without capturing — see `POST /cobrancas/{id}/capturar`.
</ResponseField>

<ResponseField name="referencia_externa" type="string">
Your own identifier — order, invoice. Echoed back without interpretation.
</ResponseField>

<ResponseField name="motivo_recusa" type="string">
Present only when `status` is `recusada`. The full catalog is in Operation › Decline codes.
</ResponseField>

<ResponseField name="criado_em" type="string">
When the charge was created.
</ResponseField>

## Errors

| Status | When |
| --- | --- |
| `401` | The key is missing, invalid, or from another environment. |
| `404` | The charge does not exist on this account. |
| `409` | The authorization expired, or the charge is not capturable. |
