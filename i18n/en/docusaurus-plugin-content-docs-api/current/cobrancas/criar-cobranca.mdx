# Create a charge

<VerbBadge verb="POST" /> `/cobrancas`

Creates a charge in `pix`, `boleto`, or `cartao`. The response is `201` even when the method declines — a decline is an outcome, not an error.

## Parameters

<ParamField name="Idempotency-Key" type="string" required>
A key you choose, up to 255 characters. Repeating the call with the same key and the same body, within 24 hours, returns the original response instead of creating again.
</ParamField>

## Body

<ParamField name="valor" type="integer" required>
In cents. Always an integer.
</ParamField>

<ParamField name="meio" type="string" required>
The payment method.

Possible values: `pix`, `boleto`, `cartao`.
</ParamField>

<ParamField name="moeda" type="string" default="BRL">
Only `BRL` today. The field exists for the day it is not.
</ParamField>

<ParamField name="capturar" type="boolean" default="true">
Card only. `false` authorizes without capturing.
</ParamField>

<ParamField name="referencia_externa" type="string">
Your own identifier — order, invoice.
</ParamField>

<ParamField name="pagamento" type="object">
The data of the chosen method. The inner key is the method name.

<Expandable title="pagamento object" defaultOpen>

<ParamField name="cartao" type="object">
Present when `meio` is `cartao`.

<Expandable title="cartao object">

<ParamField name="token" type="string">
The token from browser-side tokenization, never the card number.
</ParamField>

<ParamField name="parcelas" type="integer" default="1">
From 1 to 12.
</ParamField>

</Expandable>
</ParamField>

</Expandable>
</ParamField>

## Response

<ResponseField name="id" type="string">
The charge identifier, prefixed `cob_`.
</ResponseField>

<ResponseField name="status" type="string">
The current state. `recusada` is a successful `201` — the request was correct and the financial system said no.

Possible values: `pendente`, `paga`, `recusada`, `expirada`, `cancelada`, `estornada`.
</ResponseField>

<ResponseField name="valor" type="integer">
In cents. Always an integer.
</ResponseField>

<ResponseField name="moeda" type="string" default="BRL">
Only `BRL` today. The field exists for the day it is not.
</ResponseField>

<ResponseField name="meio" type="string">
The chosen payment method.

Possible values: `pix`, `boleto`, `cartao`.
</ResponseField>

<ResponseField name="capturar" type="boolean" default="true">

## Errors

| Status | When |
| --- | --- |
| `400` | The request is not valid against the contract. |
| `401` | The key is missing, invalid, or from another environment. |
| `422` | The request is valid and the values are not. `detalhes` carries all of them. |
