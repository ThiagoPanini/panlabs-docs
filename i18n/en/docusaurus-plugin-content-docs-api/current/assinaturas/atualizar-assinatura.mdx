# Update a subscription

<VerbBadge verb="PATCH" /> `/assinaturas/{id}`

Changes the plan of an active subscription. The change takes effect from the next cycle.

## Parameters

<ParamField name="id" type="string" required>
The subscription `id`.
</ParamField>

<ParamField name="plano" type="object">
The amount and the cadence.

<ParamField name="nome" type="string">

<ParamField name="valor" type="integer">
In cents.
</ParamField>

<ParamField name="intervalo" type="string">
The cadence.

Possible values: `mensal`, `anual`.
</ParamField>

</Expandable>
</ParamField>

## Response

<ResponseField name="id" type="string">
The subscription identifier, prefixed `sub_`.
</ResponseField>

<ResponseField name="cliente_id" type="string">

<ResponseField name="status" type="string">

</ResponseField>

<ResponseField name="meio" type="string">

<ResponseField name="valor" type="integer">

<ResponseField name="intervalo" type="string">
