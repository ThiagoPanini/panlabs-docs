# Create a subscription

<VerbBadge verb="POST" /> `/assinaturas`

Creates a subscription over a customer and an already-saved method.

## Parameters

<ParamField name="Idempotency-Key" type="string" required>
A key you choose, up to 255 characters. Repeating the call with the same key and the same body, within 24 hours, returns the original response instead of creating again.
</ParamField>

## Body

<ParamField name="cliente_id" type="string" required>
The `id` of the billed customer.
</ParamField>

<ParamField name="meio" type="string" required>
Boleto does not recur on its own.

Possible values: `pix`, `cartao`.
</ParamField>

<ParamField name="plano" type="object" required>
The amount and the cadence.

<Expandable title="plano object" defaultOpen>

<ParamField name="nome" type="string">
The plan name, yours.
</ParamField>

<ParamField name="valor" type="integer">
In cents, every cycle.
</ParamField>

<ParamField name="intervalo" type="string">
The cadence.

Possible values: `mensal`, `anual`.
</ParamField>

</Expandable>
</ParamField>

## Response

<ResponseField name="id" type="string">
The subscription identifier, prefixed `sub_`.
</ResponseField>

<ResponseField name="cliente_id" type="string">
The `id` of the billed customer.
</ResponseField>

<ResponseField name="status" type="string">
`inadimplente` is the state after all retries of a charge fail, without automatic cancellation.

Possible values: `ativa`, `pausada`, `cancelada`, `inadimplente`.
</ResponseField>

<ResponseField name="meio" type="string">
Boleto does not recur on its own — it is not on this list.

Possible values: `pix`, `cartao`.
</ResponseField>

<ResponseField name="plano" type="object">
The amount and the cadence.

<Expandable title="plano object" defaultOpen>

<ResponseField name="nome" type="string">
The plan name, yours — Trilho does not validate it against a catalog.
</ResponseField>

<ResponseField name="valor" type="integer">
In cents, charged every cycle.
</ResponseField>

<ResponseField name="intervalo" type="string">
The billing cadence.

Possible values: `mensal`, `anual`.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_cobranca_em" type="string">
Null when `status` is `cancelada`.
</ResponseField>

<ResponseField name="cancelada_em" type="string">

</ResponseField>

<ResponseField name="criado_em" type="string">
