# List subscriptions

<VerbBadge verb="GET" /> `/assinaturas`

The account’s subscriptions, most recent first, cursor-paginated.

## Parameters

<ParamField name="limite" type="integer" default="20">
How many items per page. Maximum 100.
</ParamField>

<ParamField name="a_partir_de" type="string">
The cursor of the last page read. Omit to get the first page.
</ParamField>

<ParamField name="status" type="string">
Filters by a single status.
</ParamField>

## Response

<ResponseField name="dados" type="array of object">
The subscriptions on this page.

<Expandable title="each item of dados" defaultOpen>

<ResponseField name="id" type="string">
The subscription identifier, prefixed `sub_`.
</ResponseField>

<ResponseField name="cliente_id" type="string">
The `id` of the billed customer.
</ResponseField>

<ResponseField name="status" type="string">
`inadimplente` is the state after all retries of a charge fail, without automatic cancellation.

Possible values: `ativa`, `pausada`, `cancelada`, `inadimplente`.
</ResponseField>

<ResponseField name="meio" type="string">
Boleto does not recur on its own — it is not on this list.

Possible values: `pix`, `cartao`.
</ResponseField>

<ResponseField name="plano" type="object">
The amount and the cadence.

<Expandable title="plano object" defaultOpen>

<ResponseField name="nome" type="string">
The plan name, yours — Trilho does not validate it against a catalog.
</ResponseField>

<ResponseField name="valor" type="integer">
In cents, charged every cycle.
</ResponseField>

<ResponseField name="intervalo" type="string">
The billing cadence.

Possible values: `mensal`, `anual`.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_cobranca_em" type="string">
Null when `status` is `cancelada`.
</ResponseField>

<ResponseField name="cancelada_em" type="string">
When the subscription was canceled.
</ResponseField>

<ResponseField name="criado_em" type="string">
When the subscription was created.
</ResponseField>

</Expandable>

<ResponseField name="proxima_pagina" type="string">
The cursor for the next call. Null on the last page.
</ResponseField>
