# Esteira.gerar

**Função** · `panlabs.esteira.Esteira.gerar`

Valida antes de escrever, e nunca emite saída parcial: ou o YAML descreve a esteira completa, ou não há YAML. Um workflow que roda faltando um passo passa, e passar sem verificar é pior que não rodar.

Com `diff=True` nada é escrito. É o modo que a esteira de verificação usa para reprovar quando o YAML commitado deixa de ser o que o Python produz.

## Parâmetros

<ParamField name="destino" type="Path | str" required>
O diretório onde o YAML é escrito. O nome do arquivo sai do nome da esteira.
</ParamField>

<ParamField name="diff" type="bool" default="False">
Compara com o que está em disco e não escreve. É o modo de conferência.
</ParamField>

## Retorno

O resultado da geração. Com `diff=True` ele traz o veredito sem ter tocado no disco.

<ResponseField name="caminho" type="Path">
O arquivo escrito, ou o que teria sido escrito sob `diff=True`.
</ResponseField>

<ResponseField name="mudou" type="bool">
Verdadeiro quando o YAML gerado difere do que estava em disco.
</ResponseField>

<ResponseField name="recusas" type="list[dict]">
As recusas encontradas. Vazia quando a esteira passa, e quando não está vazia, nada foi escrito.

<Expandable title="list[dict]" defaultOpen>

<ResponseField name="recusa" type="str">
O nome da recusa, da lista fechada.
</ResponseField>

<ResponseField name="ponteiro" type="str">
O nó ofensor, em caminho pontilhado: `trabalhos.verificar.passos[2].uses`.
</ResponseField>

<ResponseField name="detalhe" type="str">
A frase que descreve o que está errado naquele nó.
</ResponseField>

</Expandable>
</ResponseField>

## Erros

| Erro | Quando |
| --- | --- |
| `PassoSemNome` | Um passo chegou sem `nome`. |
| `ReferenciaNaoFixada` | Uma ação de terceiro está referenciada por tag. |
| `SegredoInline` | Um valor com aparência de segredo entraria literal no YAML. |
| `PermissaoAmpla` | As permissões do trabalho resolvem para `write-all`. |
