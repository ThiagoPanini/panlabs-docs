# Esteira

**Tipo** · `panlabs.esteira.Esteira`

O objeto que representa um workflow. Construí-lo não escreve nada em disco: o YAML só existe depois de `gerar`.

O nome é o que aparece na interface do Actions, e ele também vira o nome do arquivo — dois workflows com o mesmo nome no mesmo repositório se sobrescrevem sem aviso.

## Parâmetros

<ParamField name="nome" type="str" required>
O nome do workflow. Vira também o nome do arquivo, em minúsculas e com hífen no lugar do espaço.
</ParamField>

<ParamField name="em" type="list[str]" required>
Os eventos que disparam a esteira. Aceita os nomes do próprio Actions, sem tradução.
</ParamField>

<ParamField name="permissoes" type="dict[str, str] | None" default="None">
As permissões do token do workflow. Ausente, a esteira herda o default do repositório — que costuma ser mais amplo do que o trabalho precisa.

<Expandable title="dict[str, str] | None" defaultOpen>

<ParamField name="contents" type="str">
Leitura do repositório. `read` basta para qualquer esteira que não escreva commit.
</ParamField>

<ParamField name="id-token" type="str">
Emissão do token OIDC. `write` é o que permite assumir papel na AWS sem chave de longa duração.
</ParamField>

</Expandable>
</ParamField>

## Atributos

O objeto construído, com os trabalhos acumulados até aqui.

<ResponseField name="nome" type="str">
O nome recebido na construção, sem normalização.
</ResponseField>

<ResponseField name="trabalhos" type="list[dict]">
Os trabalhos acrescentados por `trabalho`, na ordem em que entraram.

<Expandable title="list[dict]" defaultOpen>

<ResponseField name="nome" type="str">
O identificador do trabalho dentro do workflow.
</ResponseField>

<ResponseField name="passos" type="list[Passo]">
Os passos do trabalho, na ordem de execução.

Os campos estão na página do tipo: [`Passo`](./passo.mdx)
</ResponseField>

</Expandable>
</ResponseField>
