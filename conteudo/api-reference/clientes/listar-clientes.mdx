# Listar clientes

<VerbBadge verb="GET" /> `/clientes`

Os clientes da conta, mais recentes primeiro, paginados por cursor.

## Parâmetros

<ParamField name="limite" type="integer" default="20">
Quantos itens por página. Máximo 100.
</ParamField>

<ParamField name="a_partir_de" type="string">

</ParamField>

<ParamField name="email" type="string">

</ParamField>
