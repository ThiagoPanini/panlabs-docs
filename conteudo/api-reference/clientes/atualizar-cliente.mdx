# Atualizar cliente

<VerbBadge verb="PATCH" /> `/clientes/{id}`

Atualiza um subconjunto dos campos do cliente. Campos omitidos ficam como estavam.

## Parâmetros

<ParamField name="id" type="string" required>
O `id` do cliente.
</ParamField>

## Corpo

<ParamField name="nome" type="string">
O nome completo.
</ParamField>

<ParamField name="email" type="string">
O e-mail.
</ParamField>

<ParamField name="telefone" type="string">
Em E.164.
</ParamField>
