# Criar cliente

<VerbBadge verb="POST" /> `/clientes`

Cria um cliente. Guardar o `id` é o que permite salvar cartão e assinatura sem repetir dados a cada cobrança.

## Parâmetros

<ParamField name="Idempotency-Key" type="string" required>
Uma chave sua, de até 255 caracteres. Repetir a chamada com a mesma chave e o mesmo corpo, dentro de 24 horas, devolve a resposta original em vez de criar de novo.
</ParamField>

## Corpo

<ParamField name="nome" type="string" required>
O nome completo.
</ParamField>

<ParamField name="email" type="string" required>
Usado para recibo e notificação.
</ParamField>

<ParamField name="documento" type="string" required>
CPF ou CNPJ, só dígitos.
</ParamField>

<ParamField name="telefone" type="string">
Em E.164.
</ParamField>

## Resposta

<ResponseField name="id" type="string">
O identificador do cliente, com prefixo `cli_`.
</ResponseField>

<ResponseField name="nome" type="string">
O nome completo.
</ResponseField>

<ResponseField name="email" type="string">
Usado para recibo e para notificação de cobrança recusada.
</ResponseField>

<ResponseField name="documento" type="string">

</ResponseField>

</ResponseField>

## Erros

| Status | Quando |
| --- | --- |
| `400` | A requisição não é válida contra o contrato. |
| `401` | A chave está ausente, é inválida, ou é de outro ambiente. |
| `422` | A requisição é válida e os valores não são. `detalhes` traz todos. |
