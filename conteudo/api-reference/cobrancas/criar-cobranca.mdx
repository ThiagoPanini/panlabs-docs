# Criar cobrança

<VerbBadge verb="POST" /> `/cobrancas`

Cria uma cobrança em `pix`, `boleto` ou `cartao`. A resposta é `201` inclusive quando o meio recusa — recusa é desfecho, não erro.

## Parâmetros

<ParamField name="Idempotency-Key" type="string" required>
Uma chave sua, de até 255 caracteres. Repetir a chamada com a mesma chave e o mesmo corpo, dentro de 24 horas, devolve a resposta original em vez de criar de novo.
</ParamField>

## Corpo

<ParamField name="valor" type="integer" required>
Em centavos. Sempre inteiro.
</ParamField>

<ParamField name="meio" type="string" required>
O meio de pagamento.

Valores possíveis: `pix`, `boleto`, `cartao`.
</ParamField>

<ParamField name="moeda" type="string" default="BRL">
Hoje só `BRL`. O campo existe para o dia em que não for.
</ParamField>

<ParamField name="capturar" type="boolean" default="true">
Só para `cartao`. `false` autoriza sem capturar.
</ParamField>

<ParamField name="referencia_externa" type="string">
O identificador do seu lado — pedido, fatura.
</ParamField>

<ParamField name="pagamento" type="object">
Os dados do meio escolhido. A chave interna é o nome do meio.

<Expandable title="objeto pagamento" defaultOpen>

<ParamField name="cartao" type="object">
Presente quando `meio` é `cartao`.

<Expandable title="objeto cartao">

<ParamField name="token" type="string">
O token da tokenização no navegador, nunca o número do cartão.
</ParamField>

<ParamField name="parcelas" type="integer" default="1">
De 1 a 12.
</ParamField>

</Expandable>
</ParamField>

</Expandable>
</ParamField>

## Resposta

<ResponseField name="id" type="string">
O identificador da cobrança, com prefixo `cob_`.
</ResponseField>

<ResponseField name="status" type="string">
O estado atual. `recusada` é uma resposta `201` bem-sucedida — a requisição estava certa e o sistema financeiro respondeu não.

Valores possíveis: `pendente`, `paga`, `recusada`, `expirada`, `cancelada`, `estornada`.
</ResponseField>

<ResponseField name="valor" type="integer">
Em centavos. Sempre inteiro.
</ResponseField>

<ResponseField name="moeda" type="string" default="BRL">
Hoje só `BRL`. O campo existe para o dia em que não for.
</ResponseField>

<ResponseField name="meio" type="string">
O meio de pagamento escolhido.

Valores possíveis: `pix`, `boleto`, `cartao`.
</ResponseField>

<ResponseField name="capturar" type="boolean" default="true">
Só para `cartao`. `false` autoriza sem capturar — ver `POST /cobrancas/{id}/capturar`.
</ResponseField>

<ResponseField name="referencia_externa" type="string">
O identificador do seu lado — pedido, fatura. Ecoado sem interpretação.
</ResponseField>

<ResponseField name="motivo_recusa" type="string">
Presente só quando `status` é `recusada`. O catálogo completo está em Operação › Códigos de recusa.
</ResponseField>

<ResponseField name="criado_em" type="string">
Quando a cobrança foi criada.
</ResponseField>

## Erros

| Status | Quando |
| --- | --- |
| `400` | A requisição não é válida contra o contrato. |
| `401` | A chave está ausente, é inválida, ou é de outro ambiente. |
| `422` | A requisição é válida e os valores não são. `detalhes` traz todos. |
