# Criar reembolso

<VerbBadge verb="POST" /> `/reembolsos`

Reembolsa uma cobrança `paga`, total ou parcialmente. Repetir cria um segundo reembolso — use `Idempotency-Key` para evitar.

## Parâmetros

<ParamField name="Idempotency-Key" type="string" required>
Uma chave sua, de até 255 caracteres. Repetir a chamada com a mesma chave e o mesmo corpo, dentro de 24 horas, devolve a resposta original em vez de criar de novo.
</ParamField>

## Corpo

<ParamField name="cobranca_id" type="string" required>
A cobrança a reembolsar.
</ParamField>

<ParamField name="valor" type="integer">
Em centavos. Omitir reembolsa o valor inteiro.
</ParamField>

<ParamField name="motivo" type="string">
Livre, seu.
</ParamField>

## Resposta

<ResponseField name="id" type="string">
O identificador do reembolso, com prefixo `reemb_`.
</ResponseField>

<ResponseField name="cobranca_id" type="string">
A cobrança reembolsada.
</ResponseField>

<ResponseField name="valor" type="integer">
Em centavos. Parcial é permitido — a soma dos reembolsos nunca excede o valor original.
</ResponseField>

<ResponseField name="motivo" type="string">
Livre, seu. Aparece no extrato do pagador quando o meio suporta.
</ResponseField>

<ResponseField name="status" type="string">
Pix e boleto concluem em minutos; cartão pode levar dias, a depender do emissor.

Valores possíveis: `pendente`, `concluido`, `falhou`.
</ResponseField>

<ResponseField name="criado_em" type="string">
Quando o reembolso foi solicitado.
</ResponseField>

## Erros

| Status | Quando |
| --- | --- |
| `400` | A requisição não é válida contra o contrato. |
| `401` | A chave está ausente, é inválida, ou é de outro ambiente. |
| `422` | O valor excede o saldo reembolsável da cobrança. |
