# Listar reembolsos

<VerbBadge verb="GET" /> `/reembolsos`

Os reembolsos da conta, mais recentes primeiro, paginados por cursor.

## Parâmetros

<ParamField name="limite" type="integer" default="20">
Quantos itens por página. Máximo 100.
</ParamField>

<ParamField name="a_partir_de" type="string">
O cursor da última página lida. Omitir traz a primeira página.
</ParamField>

<ParamField name="cobranca_id" type="string">
Filtra pelos reembolsos de uma única cobrança.
</ParamField>

## Resposta

<ResponseField name="dados" type="array de object">
Os reembolsos desta página.

<Expandable title="cada item de dados" defaultOpen>

<ResponseField name="id" type="string">
O identificador do reembolso, com prefixo `reemb_`.
</ResponseField>

<ResponseField name="cobranca_id" type="string">
A cobrança reembolsada.
</ResponseField>

<ResponseField name="valor" type="integer">
Em centavos. Parcial é permitido — a soma dos reembolsos nunca excede o valor original.
</ResponseField>

<ResponseField name="motivo" type="string">
Livre, seu. Aparece no extrato do pagador quando o meio suporta.
</ResponseField>

<ResponseField name="status" type="string">
Pix e boleto concluem em minutos; cartão pode levar dias, a depender do emissor.

Valores possíveis: `pendente`, `concluido`, `falhou`.
</ResponseField>

<ResponseField name="criado_em" type="string">
Quando o reembolso foi solicitado.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_pagina" type="string">
O cursor da próxima chamada. Nulo na última página.
</ResponseField>
