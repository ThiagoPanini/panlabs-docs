# Listar eventos

<VerbBadge verb="GET" /> `/eventos`

O histórico de eventos da conta, mais recentes primeiro — útil para reconciliar contra o que os webhooks já entregaram.

## Parâmetros

<ParamField name="limite" type="integer" default="20">
Quantos itens por página. Máximo 100.
</ParamField>

<ParamField name="a_partir_de" type="string">
O cursor da última página lida. Omitir traz a primeira página.
</ParamField>

<ParamField name="tipo" type="string">
Filtra por um único tipo, como `cobranca.paga`.
</ParamField>

## Resposta

<ResponseField name="dados" type="array de object">
Os eventos desta página.

<Expandable title="cada item de dados" defaultOpen>

<ResponseField name="id" type="string">
O identificador do evento, com prefixo `evt_`. É a chave de deduplicação.
</ResponseField>

<ResponseField name="tipo" type="string">
O nome do evento, como `cobranca.paga`.
</ResponseField>

<ResponseField name="ocorrido_em" type="string">
Quando o evento ocorreu — não quando ele chegou ao seu servidor.
</ResponseField>

<ResponseField name="versao_api" type="string">
A versão da API sob a qual o evento foi emitido.
</ResponseField>

<ResponseField name="dados" type="object">
O payload, que varia por `tipo`.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="proxima_pagina" type="string">
O cursor da próxima chamada. Nulo na última página.
</ResponseField>

## Erros

| Status | Quando |
| --- | --- |
| `401` | A chave está ausente, é inválida, ou é de outro ambiente. |
| `429` | Limite de taxa excedido. O cabeçalho diz quantas chamadas sobram. |
