# Desenvolvimento

<Untranslated />

Três tabelas de consulta, para quem chega no time ou integra com ele: o vocabulário próprio, os repositórios que o time mantém e as ofertas que ele expõe a outros times.

## Como ler as tabelas

Cada tabela é independente e não pressupõe leitura das outras duas. A coluna da esquerda é sempre o termo de busca.

## Siglas

| Sigla | Significado |
| --- | --- |
| NPS | Índice de satisfação do vendedor (net promoter score) |
| TTV | Tempo até o vendedor publicar o primeiro produto (time to value) |
| KYC | Verificação de identidade do vendedor (know your customer) |
| A/B | Teste controlado entre duas versões de tela |

## Repositórios

| Repositório | Linguagem | O que guarda |
| --- | --- | --- |
| onboarding-vendedor | TypeScript | o fluxo de cadastro e verificação do vendedor |
| painel-vendedor | TypeScript | o painel que o vendedor usa no dia a dia |
| editor-catalogo | TypeScript | o editor de produto e preço |
| experiencia-design-system | TypeScript | a biblioteca de componentes das telas do vendedor |

## Ofertas

| Oferta | Para quem | Como pedir |
| --- | --- | --- |
| Novo passo no onboarding | produto | levar ao ritual de priorização quinzenal |
| Componente novo no design system | qualquer time com tela de vendedor | abrir proposta no repositório do design system |
| Teste A/B de conversão | produto e marketing | pedir slot na fila de experimentos |
