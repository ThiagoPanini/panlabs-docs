# Resumo das Trilhas

Esta página reúne as trilhas de aprendizado do papel de API Owner: uma linha por
trilha, com o que cada uma cobre, o que ela pressupõe e em que ordem lê-las.

O conteúdo ainda não foi escrito. Ele nasce do processo de aprendizado em curso
no ambiente corporativo, e entra aqui trilha a trilha, em vez de tudo de uma
vez. Enquanto isso não acontece, use
[Links e Referências](./links-e-referencias.md) para as fontes já levantadas.
